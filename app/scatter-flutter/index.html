📘 scatter flutter 操作ガイド＆チュートリアル

【免責事項 / Disclaimer】
本アプリケーション「scatter flutter」は、Web Audio APIを用いたリアルタイム音声合成によって構築された個人制作のオリジナルWebグルーヴボックス（非公式・独立開発アプリ）です。特定の楽器メーカーや既存のハードウェア製品の公式シミュレーター・ライセンス製品ではありません。
また、ローカル音声・動画読み込み機能をご使用の際は、第三者の著作権を侵害するファイルの違法なアップロードや配布・共有を行わないよう十分ご注意ください。

1. 基本の再生とサウンドキット切替

  • 画面左上の ▶ PLAY ボタンを押すと、内蔵された8種類のミニマル・テクノ／ハウス系プリセットパターンが再生されます。
  • KIT選択: 中央パネル「SOUND CONTROL」右上のプルダウンから、Sub-80s Kit / Tech-90s Kit / Vintage PCM Kit / Crunch Box Kit など7種類のオリジナル・サウンドキットを瞬時に切り替えられます。

2. ダイレクト・ボリュームミキサー ＆ ON / M (MUTE) / S (SOLO)

  • 11個のトラックカード（BD1〜BASS）の中にある VOLスライダー で、選択トラックを切り替えずに直接音量バランスをミキシングできます。
  • 各カード下部の ON・M (MUTE)・S (SOLO) ボタンで、リアルタイムにパートごとの消音（M）やソロ再生（S：複数同時ソロ対応）が可能です。上部の 🔇 一斉MUTE / 🔊 全解除 で全体の抜き差しも行えます。

3. ⚡ LIVE FX (Z〜Mキー / マウス押下中のみ効くライブエフェクト)

  • TRACK SELECTのすぐ下にある LIVE FX パネルは、ボタン（またはキーボードの Z X C V B N M キー）を押している間だけリアルタイムに効果が発動し、離すと瞬時に元の状態へ戻ります（複数同時押し対応）。
  • SWEEP ↓ [Z] / SWEEP ↑ [X]: マスターフィルターを閉じる（ローパス）／開く（ハイパス）スイープ効果。
  • STUTTER [C]: 押している間だけ1/32の高速ゲート（スタッター）をかけます。
  • STRIP [V]: キック（BD1/BD2）、クローズドハット（CH）、テクスチャー（LP）のみを残し、他のパートを一時カットします。
  • BREAK [B]: キック（BD1/BD2）とタム（TT）を抜いて即座にブレイクを作ります。
  • DELAY THROW [N] / DIRT [M]: 押している間だけディレイのフィードバック＆センド量、またはマスターのオーバードライブ（歪み）を強力にブーストします。

4. バリエーション (A / B / C / D) と FILLイン

  • 各トラックに A / B / C / D の4種類の16ステップパターンを記憶できます。
  • ⏭ 次ループ頭で切替: 再生中にA〜Dを押すと点滅して待機し、現在の16ステップが最後まで再生された次の1拍目でスムーズに切り替わります。
  • 🔥 FILL差し込み: 有効にしてA〜D（特にDにはフィルインが初期設定されています）を押すと、即座におかず（FILL）に切り替わり、小節の終わりで元のバリエーションへ自動復帰します。

5. ローカル音源・動画ファイル (.wav / .mp3 / .mp4) の読み込み

  • トラック6〜10（OH, TT, RS, PC, LP）などを選択すると、SOUND CONTROL右上に 📂 音源/動画読込 (WAV/MP3/MP4) ボタンが表示されます。お使いの端末内のオーディオや動画ファイル（音声トラックを自動抽出）をロードしてシーケンサー上で演奏できます。
  • ※ご注意: 読み込んだ音源ファイル自体は保存されません。再度開いたときは読み込み直してください。

6. MIDI（ノート＋全CC）＆ WAV（個別Stems / 2MIX）書き出し

  • 上部の 📤 EXPORT STUDIO から、制作したパターンのMIDIファイル（サブステップ展開＆全ノブCC情報付き）や、48kHz/16bitの高音質WAVファイルをワンクリックでダウンロードできます。
  • 進捗・完了表示の保持: 書き出し中は右上のメインLCDおよびEXPORTバー内のステータスピルに進捗（例: STEM 2/6 や MIXING 2MIX）が表示され続け、完了・エラー表示は次の操作を行うまで（最低10秒間）保持されます。
  • 複数ファイルのダウンロード許可について: WAV (全Trk個別Stems) では有効なトラック分のWAVファイルを約650ms間隔で順番に保存します。ブラウザ側で「複数ファイルのダウンロードを許可しますか？」という確認バーが出た場合は「許可」を選択してください（ノートが1つもない空トラックやミュート中のトラックは自動スキップされ、完了時に STEMS DONE! (6 FILES / 5 SKIP) のように内訳が表示されます）。

7. 自動保存（オートセーブ）／スナップショット／初期化リセット

  • 自動保存（Auto-Save）: ステップ入力、音色ノブ、KIT選択、BPM、マスターノブ（DRIFT / SWING / DELAY / REVERB）、Undo/Redoなどの操作を行うたびに、ブラウザの localStorage へ全状態が自動保存され、次回ページを開き直した際にも前回の続きから再開できます。
  • スナップショット（SNAPSHOT 1〜4）: 左上「PATTERN & TRANSPORT」内の 📸 SAVE ボタンを押して点灯させた状態でスロット 1〜4 を押すと、気に入った状態を最大4つまで手動キープできます（通常時に 1〜4 を押すと即座に呼び出します）。
  • 初期化（RESET）: 🔄 RESET ボタンを押して確認ダイアログで実行すると、自動保存データを消去して工場出荷時のデモパターン状態へ戻します（※あなたが保存したスナップショット1〜4の作品データは消えずにそのまま残ります）。
