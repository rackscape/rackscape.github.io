1. 基本操作とサウンドキットの切り替え

  • 画面左上の ▶ PLAY ボタン（またはスペースキー）を押すと、内蔵されているリズムパターンが再生されます。
  • SOUND KIT切替: 中央パネル右上の「KIT」メニュー（Sub-80s Kit / Tech-90s Kit / Vintage PCM Kit / Crunch Box Kit 等）を選ぶと、全パートのシンセサイズ音色が一括で切り替わります。

2. ダイレクト・ボリュームミキサー ＆ ON / M (MUTE) / S (SOLO)

  • 下部に並ぶトラックカード（BD1〜BASS）内の VOLスライダー で、操作中のパートを切り替えずに各パートの音量を直接ミキシングできます。
  • カード下部の ON・M (MUTE)・S (SOLO) ボタンで、リアルタイムにパート別の消音やソロ再生（複数同時ソロ可）を行えます。

3. バリエーション展開 (A / B / C / D) と FILL機能

  • 各トラックに独立して A / B / C / D 4種類の16ステップシーケンスを保存できます。
  • ⏭ 次ループ頭で切替: 再生中にA〜Dを選択すると点滅待機となり、現在の小節が終わり次第、次の1拍目でスムーズにパターンが移行します（連続再生Chain設定中もそのまま維持されます）。
  • 🔥 FILL差し込み: 有効にしてA〜Dを押すと、その瞬間から一時的にフィルインパターンへ切り替わり、次の小節頭で自動的に元のパターンへ復帰します。

4. ⚡ LIVE FX（キーボード＆マウスホールド演奏）

  • TRACK SELECTのすぐ下に配置された7つのパッドは、押している間だけ効く（モーメンタリー動作）ライブ用エフェクターです。PCキーボードの Z X C V B N M キーにも対応しており、VARIATION連続再生（Chain）中や複数キー同時押しでも常時機能します。
  • SWEEP ↓ [Z] / SWEEP ↑ [X]: マスターフィルターを閉じてこもらせる（ローパス・スイープ）／開いて低域を削る（ハイパス・スイープ）効果をかけます（両方同時押しでバンドパスフィルター効果になります）。
  • STUTTER [C]: 押している間だけテンポ同期の1/32高速スライスゲートをかけます。
  • STRIP [V]: キック（BD1/BD2）、クローズドハット（CH）、テクスチャー（LP）だけを残し、他のパートを一時的にカットします。
  • BREAK [B]: 押している間だけキック（BD1/BD2）とタム（TT）を抜いてブレイクを作ります。
  • DELAY THROW [N] / DIRT [M]: 押している間だけディレイのセンド＆フィードバックを強めて飛ばす／マスターのオーバードライブ歪みを強めます。

5. ローカル音源・動画ファイル (.wav / .mp3 / .mp4) の読み込み

  • トラック6〜10（OH, TT, RS, PC, LP）などを選択すると、SOUND CONTROL右上に 📂 音源/動画読込 (WAV/MP3/MP4) ボタンが表示されます。お使いの端末内のオーディオや動画ファイル（音声トラックを自動抽出）をロードしてシーケンサー上で演奏できます。

6. MIDI（ノート＋全CC）＆ WAV（個別Stems / 2MIX）書き出し

  • 上部の 📤 EXPORT STUDIO から、制作したパターンのMIDIファイル（サブステップ展開＆全ノブCC情報付き）や、48kHz/16bitの高音質WAVファイルをワンクリックでダウンロードできます。
